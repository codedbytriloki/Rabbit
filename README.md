# Rabbit
# Link :- https://rabbit-2t8i.vercel.app/

Rabbit is a full-stack fashion e-commerce website built with React, Node.js, Express, and MongoDB.

## Features

- User registration and JWT authentication
- Product browsing, search, filters, and sorting
- Shopping cart and checkout
- Razorpay payment integration
- Order tracking and product reviews
- Admin dashboard
- Product, user, and order management
- Cloudinary image upload

## Tech Stack

- React + Vite
- Redux Toolkit
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Razorpay
- Cloudinary
